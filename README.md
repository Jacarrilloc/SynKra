# k8s-transaction-shield

🛡️ **Agente de IA sobre Kubernetes para la detección adaptativa de fraudes bancarios.**

Este repositorio contiene los artefactos de producto y especificaciones técnicas desarrollados para la asignatura **Tópicos Avanzados en Informática**, como parte de la Maestría en Ingeniería de Sistemas de la **Pontificia Universidad Javeriana** (Bogotá).

## Descripción del Proyecto

El sistema evalúa arquitecturas de Big Data enfocadas en el procesamiento de transacciones en tiempo real. Su núcleo es un agente de inteligencia artificial que utiliza algoritmos de regresión isotónica y aprendizaje no supervisado para identificar anomalías y fraudes. Este agente opera bajo límites estrictos de seguridad y permisos de solo lectura dentro de clústeres distribuidos de Kubernetes.

## Estructura del Repositorio

- `pvb.md` — Product Vision Board: Definición del problema, ventaja competitiva, riesgos críticos y modelo económico.
- `docs/` — Insumos de investigación profunda (validación, análisis de mercado y crítica adversarial).
- `specs/prd.md` — Product Requirements Document (PRD) consolidado y co-creado a partir de la visión del producto.
