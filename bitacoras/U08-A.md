### BLOQUEO: `kind create cluster` no arranca en esta máquina
`make cluster` (y `kind create cluster --retain`, tres intentos) fallan en «Preparing nodes» con `could not find a log line that matches "Reached target .*Multi-User System.*"`. `docker logs synkra-control-plane`:
```
Failed to create control group inotify object: Too many open files
Failed to allocate manager object: Too many open files
Exiting PID 1...
```
`sysctl fs.inotify.max_user_instances` = 128 (el contenedor corre con uid 0 del host, que ya consume el cupo con los clústeres `gitops2` y `m08-gitops1` y sus contenedores). Subirlo exige `sudo sysctl` o un contenedor privilegiado que cambie un sysctl del host: ambos están prohibidos. No se tocó ningún otro clúster. Pendientes por esta causa: CA-1 (parte clúster), CA-2, CA-3, CA-4 completo, CA-6, CA-7, CA-9 y CA-8 de guardia/receta; CA-10 se genera al final. Los scripts `ca1.sh`..`ca10.sh` ya están escritos para correrse en cuanto el cupo se libere (p. ej. `sudo sysctl fs.inotify.max_user_instances=512` por Julian).
