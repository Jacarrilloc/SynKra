```
$ docker build --no-cache -t synkra-backend backend/ 2>&1 | grep -i 'transferring context'
#3 transferring context: 193B done
#6 transferring context: 107B done
```
BuildKit transfiere incrementalmente (el contexto ya estaba en su caché local), así que esas cifras no miden el contexto. Medición directa del contenido del contexto con un Dockerfile auxiliar (fuera del repo) que hace `COPY . /ctx` y lista:
```
/ctx/build/libs/backend-0.1.0.jar  42253555 bytes
```
Es el único archivo (sin -plain, sin src ni .gradle). Pesa 42 MB (el JAR gordo), no "unos MB": es el tamaño del JAR.
